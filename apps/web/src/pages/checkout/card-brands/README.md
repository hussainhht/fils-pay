# Card brand assets

Unmodified `flat/visa.svg`, `flat/mastercard.svg`, and `flat/amex.svg` from
[SVG Credit Card & Payment Icons](https://github.com/aaronfagan/svg-credit-card-payment-icons),
retrieved 2026-10-30. Apache 2.0 license included in `LICENSE`.
Brand marks remain the property of their respective owners. These assets are
served locally; entering a card never causes a request to an external icon host.

IIN/grouping references (presentation and client validation only):
[Visa card input](https://design.visa.com/patterns/card-input/) and
[Braintree credit-card-type](https://github.com/braintree/credit-card-type/blob/main/src/lib/card-types.ts).
Visa lengths include the union of these references (13, 16, 18, 19).
The simulator has no network acceptance contract; generic card imagery does
not promise acceptance by a live processor.
